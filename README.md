# 📚 Website Book - Bách Khoa Sách
## Team Project: 4 members – HCMUS

### 📌 Mô tả dự án  
**Website Book** là một nền tảng thương mại điện tử cho phép người dùng tìm kiếm, đánh giá và mua sách trực tuyến từ nhiều thể loại khác nhau, phục vụ nhu cầu học tập và giải trí.

---

### 🚀 Tính năng chính
- 👤 Đăng ký / Đăng nhập người dùng  
- 🛒 Giỏ hàng và đặt hàng  
- 🔍 Tìm kiếm, lọc sách theo thể loại, tác giả, giá  
- ⭐ Đánh giá, bình luận sách  
- 🛠️ Quản trị sách (Admin)  

---

### 🛠️ Công nghệ sử dụng
- **Frontend:** HTML, CSS, Vue.js 
- **Backend:** Node.js, Express.js  
- **Database:** PostgreSQL  
- **Authentication:** JWT, OAuth  
- **Deploy:** Render
